## Course Description
(2-2-3) Survey of the many technologies that are used to program multi-tiered, client/server, database-intensive, Web-based applications. Students will learn languages and tools for producing static web pages, generating content dynamically on the client (browser) side, generating content dynamically on the server side, and server interaction with databases. Coverage includes HTML, CSS, PHP, JavaScript, AJAX, XML, MySQL, Web 2.0, web hosting, traffic, advertising, security and legal issues. PR: CSC 103, CSC 104 or CSC 121.

## Textbook
_Full Stack Web Development for Beginners_ by Sam Scott. [https://ecampusontario.pressbooks.pub/webdev/](https://ecampusontario.pressbooks.pub/webdev/).

## Purpose of the Course
Web development is a core modern computing skill. Web apps are everywhere, and employers need people who can create reliable, accessible, data-driven applications. This course gives you practical abilities you can use immediately in internships, jobs, or personal projects. The same core that we will cover -- client/server communication, data modeling, validation, security, testing, debugging, and thoughtful user interface design -- show up in mobile apps, desktop apps, and back-end systems as well. This course provides a durable foundation for understanding how software is structured, how data moves, how to diagnose problems, and how to build reliable applications that users can trust.

## Student Learning Outcomes
Upon completion of this course, the student (you!) should be able to demonstrate proficiency in the use of a number of technologies comprising a “full-stack” web development toolbox. In particular, you will be able to:

- Design and implement standards-compliant, accessible, and responsive front-end interfaces using semantic HTML, modern CSS layout, and client-side JavaScript.
- Develop interactive web app features that use DOM manipulation, event handling, form validation, and asynchronous data retrieval via JSON APIs.
- Build and test server-side functionality that processes requests, applies input validation, and returns structured JSON responses to support modern web application architecture through clean client-server integration.
- Interact with a relational database using SQL.
- Use development tools and workflows (Git, GitHub, DevTools, LAMP stack) to support development, testing, and deployment.
- Use generative AI tools effectively and responsibly for web development tasks, including planning, code generation, debugging, testing, documentation, and accessibility and security reviews.

## Academic Integrity
Students are expected to have read carefully and understood the rules governing breaches of academic integrity that are to be found in the College Catalog and the Viking Code. 

**All assignments turned in for this course must be your own work.** You should not copy solutions from another source (person/website), although you may use AI tools (see next section). If you use any online or written sources to inform your own work, you must clearly cite these sources in your code/solution and, as applicable, use quotations to clarify the scope of attribution or provide chat prompts used. 

Unless stated otherwise, assignments must be done alone. You are welcome to discuss any parts of the assignments with the instructor. With your friends, you may talk *about* the assignment: e.g., how far along you are, how long you anticipate needing, etc. You may not, however, discuss solutions. If in doubt about whether you can discuss something, ask the instructor.

You are responsible for keeping your files private through appropriate access protections. If you fail and someone copies your work, you too will be held responsible for violation of this policy. The same holds for other kinds of “sharing”, such as leaving your work visible in public places (whether computer screens or whiteboards). Another important kind of file-sharing is posting solutions on a publicly-visible version control repository site. If you host your work on such a site, make sure it is in a private repository.

Any violations of academic integrity will be reported to the Office of the Provost and will result in sanctions ranging from (at a minimum) loss of credit for the assignment to a final grade cap of C. Repeat violations on multiple assignments will result in an overall failing grade (F) or withdrawal from the course, at the instructor's discretion.

## AI Usage
We will be actively using AI tools in this course, in particular, GitHub Copilot in VS Code. With each assignment that you submit, you should include a brief statement of how you used AI tools to help you complete the assignment along with complete transcripts of your chat logs/prompts. You may not submit AI-generated work as if it were your own: without attaching attributive documentation that records the GenAI interaction used to generate a particular artifact. 

 You should not use AI tools to generate output that you do not understand. You are expected to understand and be able to explain any code generated by AI tools that you submit.

Please be aware that even when a tool like Copilot does produce "correct" code, it may fail to meet expectations for being well-organized, efficient, and clean. You are responsible for the quality of the code you submit. If you are not sure, please ask the instructor for review prior to submission. Additionally, you are responsible for understanding and being able to present and explain every line of generated code, upon request. You should not use AI tools to generate output that you do not understand. You should ask the instructor to go over any code you do not understand *before* you submit it.
