# Creative Project

## Overview

A significant portion of your learning outcomes for this course is associated with a major web development project. This project attempts to approximate the development process of a “real world” web application. To that end, it has three overarching purposes:

- ### Incorporating several popular web development technologies
    Much of the time, the tools and programming languages taught in a classroom setting are learned and practiced in isolation from one another. Although this focus is conducive to learning concepts for the first time, it is not typically representative of how software is developed for applications in industry. The ability to make different technologies “play nicely” with one another effectively, efficiently, and elegantly is a key strength of successful software engineers.

    This web development project will give you an opportunity to develop the important skill of integrating various technologies with one another in a single application. 

- ### Using an iterative development process
    One element used in industrial software development today is the concept of project iterations. In this approach, a large project is broken down into several smaller tasks and features, each of which is designed, developed, and deployed on its own timeline (sometimes consecutively, sometimes in parallel with one another). This technique of “ship early, ship often” fosters greater confidence and flexibility in each component of the project, as the entire solution is built incrementally over several releases.

    Your creative project will take an iterative strategy in its implementation. Throughout the course, you will create and launch several project milestones, small releases of feature subsets which will gradually lead to the completion of a complex web application. 

- ### Encouraging creativity in development and implementation
    There is an undeniably artistic and creative side to software development. Embracing this aspect of the process makes one’s work more enjoyable and meaningful, provides motivation to carry it through to completion, and raises the quality of the final product. Towards this end,  the requirements for this project will address the basic functionality of the system as well as provide guidance regarding the tools used to build it. Beyond that, it is up to you to design the user experience ("look and feel") and the functionality of the web application. 


## High Level Requirements

For this project, you will build a web application that solves a problem, or addresses a need or interest, of your own choice. The system should be interactive with the user (e.g. through forms, or event handling), involve multiple pages/displays, and interact with data from some source - either user-generated through the application, or an existing online database/api.

The system will be built using the following technologies:

- Front-end user experience crafted with HTML, CSS, and Javascript.
- Data managed in a server database, manipulated using SQL, potentially imported from an external api or datasource (e.g. csv file).
- A back-end web application written in PHP providing a JSON web service API interface.


## Milestones

- ### CP Proposal - Due: September 8th

    Provide a proposal of the web application you would like to build. Be ambitious, and take into account that it should involve interaction with multiple, authenticated users, and will eventually generate or access a significant source of data. (Even if we haven't talked about how to implement any of that at this point.) I will help you refine your proposal to make sure it is realistic, and set specific mini-milestones for each milestone throughout the semester. 

    Your proposal should include a low-/mid-fidelity "wireframe" (read: [https://balsamiq.com/blog/what-are-wireframes/](https://balsamiq.com/blog/what-are-wireframes/). or [https://careerfoundry.com/en/blog/ux-design/what-is-a-wireframe-guide](https://careerfoundry.com/en/blog/ux-design/what-is-a-wireframe-guide). ). You can use Microsoft Powerpoint to build wireframe diagrams/images, or an online tool for the purpose. [Figma](https://www.figma.com/templates/wireframe-kits/) and [Lucid](https://lucid.co/diagram/wireframe) are some currently popular options.


- ### CP MVP - Due: September 22nd

    Build a minimum viable product (MVP) of your web application. This should be a working prototype with end-to-end functionality that demonstrates the core features of your application. The MVP should include a basic operational user interface, reasonable styling, and interaction with a database and/or data files on the server.
